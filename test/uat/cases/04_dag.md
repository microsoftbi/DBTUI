# TC-DAG — DAG 可视化测试用例

## 前置条件
- 已创建 duckdb 项目并完成首次 parse
- 进入项目详情页 → DAG 标签

---

### TC-DAG-01 节点与边

| 项 | 内容 |
|---|---|
| 优先级 | P0 |
| 步骤 | 查看 DAG 图 |
| 预期 | 1. 至少有 1 个 model 节点 + 1 个 test 节点<br>2. 节点之间有箭头连接 |

### TC-DAG-02 类型着色

| 项 | 内容 |
|---|---|
| 优先级 | P1 |
| 步骤 | 对照图例查看节点颜色 |
| 预期 | model 节点为蓝色、test 节点为橙色、source 节点为绿色（如有） |

### TC-DAG-03 搜索与筛选

| 项 | 内容 |
|---|---|
| 优先级 | P1 |
| 步骤 | 1. 在搜索框输入 `example`<br>2. 取消勾选 `test` 类型 |
| 预期 | 1. 搜索后只显示匹配的节点<br>2. 取消类型后对应节点消失 |

### TC-DAG-04 血缘高亮

| 项 | 内容 |
|---|---|
| 优先级 | P1 |
| 步骤 | 1. 点击 `example` 模型节点<br>2. 观察其他节点 |
| 预期 | 1. 选中节点高亮<br>2. 上下游节点正常显示，无关节点变暗 |

### TC-DAG-05 点击运行

| 项 | 内容 |
|---|---|
| 优先级 | P0 |
| 步骤 | 1. 点击 `example` 节点 → 底部信息栏点「运行」<br>2. 观察节点状态变化 |
| 预期 | 1. 弹出运行对话框<br>2. 运行中节点显示蓝色呼吸动画<br>3. 完成后变为绿色（成功） |

### TC-DAG-06 缩放

| 项 | 内容 |
|---|---|
| 优先级 | P2 |
| 步骤 | 点击工具栏的 + / − 按钮 |
| 预期 | DAG 图平滑缩放 |
